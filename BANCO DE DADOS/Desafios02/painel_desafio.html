Etapa 1: Leitura de Dados (SELECT) LocalStorage

Abra o arquivo minha_aplicacao.html. Sua primeira tarefa é fazer a função obterAlunos() buscar os dados gravados no navegador sob a chave 'ete_alunos_db'.

💡 Dica de Implementação:
Use localStorage.getItem(CHAVE_BANCO). Lembre-se que os dados no LocalStorage são armazenados como texto, então você deve converter com JSON.parse(). Se não houver nada salvo, retorne um array vazio []. 
function obterAlunos() {
  const dados = localStorage.getItem(CHAVE_BANCO);
  return dados ? JSON.parse(dados) : [];
}

Etapa 3: Inserção de Registros (INSERT INTO) Formulário

Crie o objeto const novoAluno = { id: novoId, nome, telefone, cidade };, adicione com alunos.push(novoAluno) e salve usando localStorage.setItem() com JSON.stringify().
Etapa 4: Exclusão de Registros (DELETE) Array Filter

Implemente a função deletarAluno(id) para remover um registro do LocalStorage quando o botão for clicado.

💡 Dica de Implementação:
Use o método .filter() para gerar um novo array mantendo apenas os elementos onde a ID for **diferente** da ID passada como parâmetro: 
function deletarAluno(id) {
  let alunos = obterAlunos();
  alunos = alunos.filter(aluno => aluno.id !== id);
  salvarAlunos(alunos);
  carregarTabela();
}
